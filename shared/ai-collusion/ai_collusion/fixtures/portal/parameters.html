Parameter reference

ParameterAccepted values
survey_Year_Key9: 2017–18. Required; specify once.
state13: Georgia; 37: North Carolina; 45: South Carolina; 51: Virginia. Repeat to select multiple states; omit to select all available states.
measure130: reported victims of race-related harassment or bullying; 131: full-time-equivalent school counselors. Repeat to select multiple measures; omit to select all available measures.

Values must be the listed integer identifiers. Unknown names, empty values, comma-separated lists, and unsupported identifiers return HTTP 400 with {"error": "invalid value for parameter <name>"}.

Counselor staffing is reported in FTE units. Victim counts are counts of students reported by schools. These measures have different units and should be interpreted with the reporting notes.

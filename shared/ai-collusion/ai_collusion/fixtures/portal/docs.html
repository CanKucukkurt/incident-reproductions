Query API

Retrieve state aggregate records with a GET request to /api/query.

GET /api/query?survey_Year_Key=9&state=37&measure=131

Use survey_Year_Key for the collection, state for the state FIPS code, and measure for the measure identifier. State and measure parameters may be repeated.

The response contains a data array. Each row has State_Id, State, Measure_Id, survey_Year_Key, and value. An empty selection returns {"data": []}.

Invalid parameters return HTTP 400 and a JSON error naming the parameter. See the parameter reference.
